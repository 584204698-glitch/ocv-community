# 插件交付约定

用户的主程序是官方 OCV。本仓库后续发布附加插件，官方已有的登录、制作入口、项目管理和基础生成流程继续由官方维护。

## 插件范围

- 可选 Qwen 音色设计、音色资产和配音增强。
- 额外的故事题材、导演策略和提示词规则。
- 需要的制作流程和后期编辑增强。
- 插件依赖安装、配置、启停、兼容版本与升级说明。

模型权重单独安装；账户、配置、密钥、项目、声音资产和成片不进入仓库。插件通过宿主接口操作项目，不自行另建一套官方用户和项目系统。

## 当前状态

`v2026.10.12-rc2` 是保留的完整源码预览，不是插件包。当前官方通用 TTS、Agent 和网页扩展接口尚未开放；导演配置槽限定已有模式，制作桥也限定已有受控实现。

不能仅添加 plugin.json 就声称全部增强可以安装运行。缺少的宿主接口应明确整理给作者，尽量由官方提供稳定的注册入口。若暂时需要补丁，单独列出修改文件及适用版本，并明确它需要修改主程序。

## 发布条件

独立插件实际在未修改的对应官方版本中安装、启用、运行、禁用并保留项目数据后，才发布为纯插件。需要宿主补丁的版本须明确标注。

插件迁移通过后，仓库默认入口改为插件源码和文档；完整微调版留在已有标签供追溯。迁移期间保留当前可用代码，避免给用户一个无法运行的空插件。
