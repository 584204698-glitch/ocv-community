# 固定题材提示词

OCV 共用生产流程，按采用故事的题材选择固定提示词补充规则；不会为每部作品临时创建代理或新增模型调用。通用代理始终保留。动漫是画风，不能仅凭“日系动画”判断故事属于喜剧、悬念还是奇幻。

当前覆盖已有九种故事预设：通用、温暖关系、日常微悬念、奇幻规则、微缩世界、儿童绘本、搞笑日常、科幻生活、知识故事。各预设同时提供写作、分镜导演及故事审核规则。绘本保留原有独立写作者。未知题材或直接导入而没有题材依据的稿件使用通用规则，不猜测用户选择。

选择依据来自采用稿的 `story_snapshot.brief.preset`，不读取其他项目或历史声音。题材规则不能修改采用台词、角色ID、音轨路线或素材绑定。已规划的项目不会因为新增规则而自动重新调用模型；显式重新规划才生成新方案。

修改位置：

- `backend/app/story_genre_profiles.py`：固定规则与通用兜底。
- `backend/app/story_writer.py`、`story_development.py`：写作时选择规则。
- `backend/app/video_native_story.py`：采用稿到分镜导演的规则传递。
- `backend/app/video_dialogue_story_review.py`：审核使用对应题材标准，保留原有硬性校验与建议分类。

动态视频转换代理继续只执行已经批准的动作，不因题材自行增加事件。后续经典桥段实片遇到现有规则无法覆盖的体育竞技、动作追逐等问题时，依据实际失败增加固定规则；新增题材须同时接入正常网页选择与采用稿快照，不能只在测试脚本里指定。

本轮实现已通过本地测试，部署与实片结果另行记录；该文档不表示九种题材均已通过成片验收。
