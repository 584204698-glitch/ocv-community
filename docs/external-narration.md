# 独立旁白与 H3 角色对白

在动态视频步骤的“全片动态方案二次编辑”中，将旁白路线设为“独立旁白 · IndexTTS2.5”。旁白须先采用固定音色；角色仍可选择参考音色或 H3 自行生成声音。切换只保存路线，不立即生成素材。原生 H3 旁白路线继续保留。

点击生成本镜后，先用现有 IndexTTS2.5 运行器合成旁白，实测 WAV 时长，并按账号、项目、文本、参考声音内容缓存。重试、换图不重复合成相同旁白。只有旁白文本或音色变化时才产生新旁白资产。

旁白需要的时间超出原时段时，后续动作和角色发言按同一时间映射顺延，不加速声音。原有动作顺序与静默间隙保留，画面生成时长向上取整。超过 H3 的15秒上限时保留合成音频并提示调整本镜；本版不自动拆分已确认的核心图片。页面上的原规划时间与实际请求时间可能不同，以本镜实际提交时长为准。

H3 的实际提示词与声音参考只包含角色对白，旁白不作为声源进入 H3。旁白期间的画面仍执行原定非语言动作。纯旁白镜头采用动作与环境声生成；混合镜头保留角色台词。

生成后先识别 H3 原音轨，核对角色台词及实际时间，检查是否侵入旁白时段。原声异常、时间重叠或音频缺失时不强行混音；原片保留，界面说明旁白预览未完成。ASR不能证明口型、说话者、声线正确，也可能误识别，需要观看和试听复核。

若原视频已经生成而混音未完成，可点“重新检查并混合旁白”。此入口只检查已有原声、读取冻结的旁白文件并混音，不调用语言模型、TTS 或 H3。原声实际错词或发言重叠不会因此自动变正确，仍会显示具体原因；不要反复点击期待重新生成不同内容。

预览与导出都保留 H3 环境声及角色声音，再按旁白时间混入独立音频。没有整轨静音、覆盖异常对白或靠剪掉尾音通过。导出字幕分别采用角色语音识别时间与旁白实际时间。旧原生视频不会自动变成新路线；含旁白的旧镜头须显式重做，其他镜头无需因此重建。

修改入口：`video_external_narration.py`（缓存、合成、时间映射、混音）、`video_dialogue.py`（H3声源投影）、`video_generation.py`（生成与预览）、`video_native_export.py`（混合导出）、`video_studio.py`（路线切换）、`NativeProjectRevision.vue`（网页入口）。

部署及代码测试不等于实片验收。先验证单镜无旁白串嘴，再验证旁白与角色对白的交接，不建议未经验证直接整片重跑。
