# 动态成片的旁白音量

合成与导出新增独立的旁白音量，范围0%–100%。50%指振幅系数0.5，约为−6.02 dB，不表示主观听感恰好减半。改变后重新合成即可，无须重新生成配音、图片或视频。

`POST /api/video-studio/{id}/export` 可选 `narration_volume` 为0到1之间的有限浮点数。省略时沿用该项目已保存的合成设置；无旧设置时保持1.0。前端项目切换恢复各自设置，轮询同项目不覆盖尚未提交的滑块值。

参数仅用于后期旁白轨，原始配音文件不改。启用片段原声时沿用其0.65系数，与旁白通过不自动归一化的amix合成；limiter关闭自动补偿增益。关闭片段原声时，同样应用旁白系数，仍保留配音末尾与时间轴补齐行为。

验证包括真实FFmpeg短片：旁白独占的时段，0.5设置相对1.0的RMS约减半；音效独占的时段，音效保持不变。两种原声开关均覆盖，原音频字节和时长保留。音量调节不负责识别或去除视频模型生成的未经批准对白。
