# 发布边界

1. 只发布可选增强模块、安装辅助和必要接口说明，不发布官方核心文件、功能替代补丁或官方升级内容。
2. 官方吸收的功能直接使用官方实现；不得继续发布一个更低上限的副本。附加模块使用宿主能力预检，不固定参考图数量，不截断输入。
3. 官方尚缺的执行接口明确写入接入说明，保持对应功能未接入状态；清单可见不代表增强可运行。
4. 不公开私人栏目、账号路线、专有提示词、项目、声音与媒体资产、模型权重、密钥、运行配置或私人 Git 历史。
5. 每次更新只显式暂存审查后的公共文件，检查安装保护、源码来源、发布边界和隐私，再发布标签；不从私人主程序整库推送。

`tools/verify_source_bundle.py` 验证附加源码与包清单；`tools/check_release_scope.py` 检查待发布索引不含宿主补丁/维护包；`tools/check_release_privacy.py` 检查待发布索引中的隐私风险。工具通过不替代宿主实测。
