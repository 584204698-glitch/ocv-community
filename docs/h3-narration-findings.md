# H3 旁白驱动可见人物开口：调查记录

2026-10-10。以下保留原生旁白调查依据；后续进展见文末。

## 已确认的官方规则

[官方 base-en 第 4.4 节](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/references/base-en.txt) 要求画外旁白使用 `says in an off-screen voiceover`，每个 `<d>` 台词块之后立即说明对应可见人物嘴唇闭合。不发声的角色不分配 `(Sx)`。

[官方 Ref2VA 规则](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/references/ref-en.txt) 区分人物 `<Subject N>` 与实际声源 `(Sx)`；独立旁白有独立声源编号。参考音频可只提供音色，不代表音频波形或台词直接复用。

当前失败镜头实际已经包含上述画外旁白短语和闭嘴要求。因此不能把再次添加同一句话称为已验证修复。

## 社区证据和局限

后续扩大到全 GitHub 检索，找到更直接的案例：

- [ComfyUI #16155](https://github.com/Comfy-Org/ComfyUI/issues/16155)：Ref2VA 加声音参考后出现额外词句、错误时序，甚至复述参考录音中的词。简化提示词并注明发言前后闭嘴后，发帖者报告带克隆参考 2/5 正确，不带参考 5/5 正确。帖子附视频，本文未逐一视听复核；样本小、硬件与权重不同，而且是场内对白，不是证明旁白串嘴同因。但足以提示需要隔离声音参考影响，不能承诺闭嘴词稳定解决。
- [H3 Director #108](https://github.com/AIMixer/ComfyUI_MiniMaxH3_Director/issues/108)：发帖者报告将插件参考节点改回 ComfyUI 原生 MiniMax H3 Reference to Video 后，异常语音及动作不足改善。属于单用户反馈。已保存的本项目工作流使用 `MiniMaxH3ReferenceToVideo`，不是该插件节点，不能直接照搬替换作为修复。
- [diffusers-workflow #608](https://github.com/dkackman/diffusers-workflow/issues/608)：项目维护者公布两种种子的实验，反驳“每个听者都必须写闭嘴”“拿着电话的人必然跟电话声音对口型”等绝对规则。另报告画外物体被命名后可能进入画面。本文读的是实验报告，未独立验证素材；不能把其英语 words/s 数据当作中文字符速率。

[MiniMax-H3 #69](https://github.com/MiniMax-AI/MiniMax-H3/issues/69) 报告参考视频动作迁移时音频长度、动作和声线不一致，没有给出经过验证的旁白口型解决方案。这与纯音色参考并非同一个问题，不能直接套用。

官方仓库 Issues 搜索 `voiceover`、`旁白` 未找到直接结果；`mouth` 返回的部署挂起问题与此不对应。Google、DuckDuckGo 搜索遇到验证码，未尝试绕过；Bing 本轮结果与查询缺乏相关性，未作为证据。这是本轮检索范围的限制，不表示不存在其他解决方法。

## 当前应用层发现

第一镜保存的提交记录把台词绑定给 `kind=narrator`、`on_screen=false` 的旁白，并带有对应音频参考。可见主角没有实际台词。记录不支持“漏交音频”或“角色ID绑定错了”的判断。

但编译器摘要仍泛称画面人物说出指定台词，且将睡眠中的人物定义为旁白的听者。这与独立画外叙述不一致。待验证补丁去掉此类场内交流描述；角色真正对话时仍保留说话者与听者关系。

这两处冲突是可确认的提示词问题；它们是否是模型串嘴的充分原因仍需实片对照。32 项提示词测试通过只能证明编译结果和绑定不回退，不能证明口型质量。

## 验证方式

若开展实片对照，应保持核心图、音频参考、台词、时长、模型、采样配置和种子相同，只比较新旧旁白提示词。同时检查嘴部动作和声音归属；ASR文字相同不能证明旁白口型正确。

把旁白独立生成再与环境声混音是不同的制作路线，不是已找到的 H3 原生旁白修复。本轮没有擅自切换路线，也没有静音原视频或覆盖异常声音。

## 后续实施进展

用户复验反馈原生旁白补丁仍未解决嘴部动作，因此用户明确同意切换至独立旁白与 H3 角色对白的混合路线。该路线已部署并开始正常网页单镜验证，详见 [独立旁白流程](external-narration.md)。旁白使用已采用的参考声音交给 IndexTTS2.5，实测时长后从 H3 台词与声音参考中剔除，再保留原始 H3 音轨进行混音。这不构成原生旁白问题已被解决或成片质量已验收的结论。
