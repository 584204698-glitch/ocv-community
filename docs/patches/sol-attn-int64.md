# 可选 Sol-Attn 长序列索引修复

仅适用于使用社区 `Saganaki22/ComfyUI-sol-attn` 的部署。官方 OCV 用户、其他视频服务和未启用该节点的用户不需要此补丁。

本轮绘本在 1344×768、8步、328帧及角色参考输入时，Triton `_reduce_kc_kernel` 报非法内存访问，随后ComfyUI执行线程退出。短镜头曾成功，不能由此推断任意长镜头均稳定。

H3融合QKV视图每行跨度为 `3 × 56 × 128 = 21504` 个元素。原内核的 `rows * stride` 使用32位有符号计算，从第99865行起超出范围。补丁在四个预处理读取位置**先将行索引提升到64位，再乘跨度**。不改变模型、采样步数、稀疏阈值或图像内容。

补丁文件：`sol-attn-int64.patch`。原文件 SHA256：`6b0dd8bc8f2ca563160bbc84751327720f6fdfa52a6a99e1c364f311d15120f1`；修复后：`b56e29a5ee5f92e69c2ea7039e4eff17b5a9d363fbfecc9ea0238df7b7a119aa`。

部署时先核对目标文件，备份，并等待共享GPU任务及guard正常结束。在该节点仓库执行 `git apply --check <补丁路径>` 再 `git apply <补丁路径>`，然后在空闲状态重启ComfyUI。若上游已修复或文件版本不符，先人工比较，不强行覆盖。不要通过杀guard、清锁或启动第二个ComfyUI来应用补丁。

静态溢出边界和四处精确改动已检查；修复后已完成一次真实H3长镜头验证：1344×768、328帧、8步、105846 tokens，ComfyUI执行472.486秒，视频完整解码通过。此结果只覆盖该输入形状，其他尺寸仍需验证。本修复作为可选部署补丁提供，OCV启动流程不会自动修改用户的ComfyUI或安装此节点。原节点版权和Apache-2.0许可证保持。
