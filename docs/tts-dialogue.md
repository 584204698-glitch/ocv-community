# TTS对白与单句情绪

新建角色对话或混合故事，选择“音频驱动与后期配音”。旧项目在“全片动态方案二次编辑”切换同名路线。为每位发言者采用固定音色；正文可选择 IndexTTS2.5 或 Qwen3-TTS 克隆。

分镜规划在同一次语言模型请求中，为每句确定情绪和强度。旧分镜按已保存的delivery表演要求保守匹配；情绪未明确、被否定或存在多个冲突情绪时，保持自然声线，不根据台词的标点或人物年龄猜测。

“本镜台词”提供自动、自然、开心、生气、悲伤、害怕、厌恶、低落、惊讶、平静。默认强度0.35，可调0至1；0不施加额外情绪。自然模式不覆盖已采用声音本身的表达。改变情绪不会重新设计人物音色，也不会额外调用语言模型重新规划已确认动作。

保存后重做本镜。未变化的台词、音色与有效情绪参数复用已缓存音频；变化的句子重新合成。实测音频决定发言窗口，后续台词和动作依序移动，不拉伸或截断配音；总长超过H3单镜上限时保留配音并提示拆镜。旁白不进入H3口型音频；角色对白按对应时段组成音频Guide。沿用开场图约束和现有画面提示词，不另加剧情或机位。

预览与导出使用TTS对白和旁白，原H3音画另行归档。此路线不保留H3原音轨中的环境声；不能将其称为原生音轨验收通过。字幕按实测配音位置写入。音频Guide属于模型约束，口型及画面稳定仍须观看实片确认；情绪参数不等于已经通过听感验收。

若原片逐句识别与台词一致，配音的实际发声长度与原片相差不超过 0.15 秒，但中间静默过长导致画面校准失败，系统尝试移动已有配音到原片实际发声位置。此回退不重跑 H3、不改变画面或声音速度；录音必须完整位于镜头内，且不能与其他对白或旁白重叠。移动结果同步用于预览、导出字幕和音轨编辑，并绑定本次视频与配音，替换素材后不会沿用旧位置。该检查只提供时序依据，无法验证说话者或逐音素口型；不满足条件时保留原时序和明确警告。

发声段长度差超过上述小偏差时，可以在保留实际开口起点的同时，使用既有画面时序校准来适配配音；每一段的画面速度变化仍限制在 0.5～2 倍，声音不拉伸、整镜不截断。配音碰撞、镜头越界、台词不一致或任何段超出速度范围时，不采用自动移动。UI 会分别标明“移动配音”或“校准画面”，均不自动宣称口型通过。
