# 用户操作说明

按照 README 安装、注册并登录，在“接口与服务”配置自己的语言、图片和配音接口。ComfyUI 使用自己的后端及工作流；源码版不会继承维护者的模型、地址或音色库。

故事工作台可导入原稿或提出创作方向。采用故事后选择旁白、对话或混合，没有时长/镜头偏好时选自动。检查角色，选择已有声音或自动设计、试听并采用；也可使用所选路线支持的原生声音方式。

开始一键制作后查看阶段状态。首次音色采用、资产确认或服务不可用时可能暂停；处理后“继续一键制作”，保留完成项。图文视频仍可直接走原入口。

局部换图/声音优先使用替换入口；改变表演才给单镜意见并同步提示词。生成后核对说话者、口型、台词及场景，必要时调整音轨位置。接口成功或 ASR 为空不等于质量通过。

失败先看本镜错误和任务日志：已有任务先查询/取消；缺模型按声音面板安装说明准备。HTTP 500 结果未知需核对服务端结果与扣费，之后再决定是否生成本镜新版本，不重跑全部素材。

导出后实际播放检查。密钥、账号、音色、项目及媒体属于本机数据，禁止提交公开仓库。
