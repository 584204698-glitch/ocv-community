# OCV 社区增强插件 · 接入源码

为[官方 OCV](https://github.com/IFRIT-Zhou/One-Click-VidGen)提供附加功能。主程序、参考图数量、图像模型适配和官方更新由 OCV 管理，本包不替换这些功能，不修改其默认设置或容量。

**当前是增强功能的接入源码，尚不是安装即用的完整插件。** 官方插件清单可以展示和启停本包，但通用 TTS、故事工作台、制作调度及网页面板仍需宿主提供执行接口。安装器只登记清单，不会使下表功能自动生效。具体缺口和接入位置见[作者接入说明](integration/AUTHOR_GUIDE.md)。

## 增强功能

| 功能 | 本包提供 | 当前状态 |
|---|---|---|
| 可选 Qwen3-TTS | 音色设计、参考声音复用、独立模型环境安装工具 | 安装辅助可独立使用；OCV 配音入口待接入 |
| 角色声音管理 | 项目角色与声音绑定、声音库、角色表达建议 | 附加模块与面板，待宿主接入 |
| 故事创作工作台 | 创意展开、故事修订、采用稿追踪、通用题材规则 | 附加模块与面板，待宿主接入 |
| 多角色对白制作 | 独立旁白、对白时序、音色参考、后期音轨编辑 | 附加模块与面板，待宿主接入 |
| 一键制作与恢复 | 阶段协调、任务状态、保留素材与局部恢复 | 附加模块与面板，待宿主接入 |
| 手工制作控制 | H3 提示词编辑、动态节奏选项、画风预览 | 附加模块与面板，待宿主接入 |

源码位于 `plugins/ocv_community/extension_src`，保留宿主相对导入，供开发者接入。不能直接当成独立 Python 包运行；不应覆盖到官方源码目录。

## 安装与检查

需要 Python 3.10 或更高版本；登记、检查不加载模型。

```powershell
python tools/install_plugin.py --ocv-root "C:\OCV"
python tools/install_plugin.py --ocv-root "C:\OCV" --install
python tools/check_host.py --ocv-root "C:\OCV"
```

首条命令预览。第二条只新增 `plugins/ocv_community`，不改核心源码、配置或项目；同名目录存在时拒绝覆盖。能力检查会如实报告尚缺的接口。不要为了通过检查伪造能力声明。

独立 Qwen 安装辅助见[插件说明](plugins/ocv_community/README.md)。默认不安装依赖、不下载模型、不执行推理。

## 与官方的边界

官方已有或新增加的功能直接使用官方实现，包括参考图数量、重绘选择器、图像请求、任务队列和生产桥。本包不发布这些功能的替代补丁，不把官方更新算成社区增强。

v0.1.2 曾错误加入四图维护补丁；现已从当前发行内容移除，同时撤下旧宿主补丁和自带图像传输实现。**不要把旧版本补丁应用到新版 OCV。** 已手动应用旧补丁的开发者应按自己的代码差异恢复官方实现；本安装器不会擅自改动现有安装。详见[版本记录](docs/CHANGELOG.md)。

私人栏目、账号专用路线、专有提示词、项目、声音资产、媒体、密钥及运行配置不在公开包中。官方未开放的接入点只写明所需接口，不打包一套微调后的主程序。
